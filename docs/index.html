BCMPR

Batch-Constraint Manifold Partition derives proxy labels from unintegrated single-cell data geometry for dataset-specific evaluation of batch-effect removal before cell annotations are available.

Available in Python and R. Choose the language and data structure that already fit your workflow. Read the method and choose a package
