Installation

Compatibility

  • Version: 1.0.0 (Release Date: September 2026)
  • R: 4.5 or later
  • Target platforms: Linux, Windows, and macOS

Installation

install.packages("bcmp")

Verify the installation

library(bcmp)
packageVersion("bcmp")

Dependencies

Installing bcmp resolves and installs the following core packages:

  • methods (included with R)
  • Matrix
  • igraph and leidenbase
  • Rcpp, RcppAnnoy, and RcppParallel

For object workflows, install the following packages manually if they are not already installed:

  • bcmp() on Seurat objects: requires SeuratObject (≥ 5.0.0).
  • bcmp() on SingleCellExperiment objects: requires SingleCellExperiment and SummarizedExperiment.
  • If you use only one object type, you do not need the packages for the other.
  • Debug output in bcmp() requires uwot for UMAP.

For scIB metric calculation, see the environment setup in the vignette.
